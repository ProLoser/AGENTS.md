# Personal agent instructions

Personal instructions for coding agents, stored in `AGENTS.md`.

Inspect and customize the instructions before installing them. If `~/AGENTS.md` already exists, review and merge its contents manually. To copy without overwriting an existing file:

```sh
cp -n AGENTS.md ~/AGENTS.md
```

After creating an empty remote repository, publish this project:

```sh
git remote add origin <YOUR_REPOSITORY_URL>
git push -u origin main
```
